# André Luís Oliveira — Brag Document

Site estático (HTML + CSS, sem build) com resumo de conquistas e trajetória profissional.

🔗 **https://andresapao.github.io/andreoliveira/**

## Como atualizar

Tudo está no `index.html`:
- **Números do topo** → bloco `.stats-grid`
- **Conquistas** → cada `<article class="win">` (métrica, título, descrição, onde)
- **Experiência** → cada `<div class="job">` na seção `#trajetoria`

Qualquer commit na branch `main` republica o site automaticamente pelo GitHub Pages.

Dica de brag document: sempre que entregar algo relevante, anote **o que fez, o impacto (número!) e onde** — e adicione um card novo.
